How to Get Your Meta Pixel Credentials

You need 2 things from Meta: your Pixel ID and a CAPI Access Token. Here's exactly where to find them.

1
Open Meta Events Manager
Go to business.facebook.com/events_manager

Make sure you're logged into the correct Facebook/Meta Business account that owns your ad account.
2
Find Your Pixel ID
In the left sidebar, click Data Sources.

Click on your Pixel (it shows as a blue lightning bolt icon ⚡).

Your Pixel ID is the 15-16 digit number shown at the top of the page, right below the pixel name.

Example: 1234567890123456
📸 Pixel ID is shown under your pixel name at the top of the Overview tab
3
Generate a CAPI Access Token IMPORTANT
While still on your Pixel page, click the Settings tab (top navigation).

Scroll down to find the section called "Conversions API".

Under "Set up through partner integration", find the Access Token row.

Click "Generate access token".

Copy the long token that appears — it starts with EAA... and is very long.

⚠️ Copy it immediately — it won't be shown again in full.
📸 Settings tab → Conversions API section → Generate access token button
4
Don't have a Pixel yet?
Go to Events Manager → click "Connect Data Sources" → choose Web → choose Meta Pixel → give it a name → click Create Pixel.

You don't need to install any code on a website — TG Tracker fires events server-side via CAPI, so no website pixel code is needed.
5
Paste into TG Tracker
Go back to the dashboard → Accounts tab → Add Bot or Add Personal.

Paste:
• Meta Pixel ID → the 15-16 digit number
• CAPI Access Token → the long EAA... token

Each account gets its own Pixel. If you have multiple bots running different campaigns, each can fire to a different Pixel.
💡 Testing your Pixel: After adding an account and creating a campaign, go back to Meta Events Manager → your Pixel → Test Events tab. Click a tracking link and watch the event appear in real time (usually within 1-2 minutes).
